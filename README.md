# TimezoneClock

原生 SwiftUI 菜单栏时钟。默认显示北京时间，点击菜单栏文字打开世界时钟。

## 使用

- 点击一个时区，将它设为菜单栏常驻时区。
- 点击右上角 `+`，搜索城市名称、时区标识或中文时区名称后添加。
- 点击时区右侧 `−` 移除；至少保留一个时区。移除常驻时区后自动切换到第一个剩余时区。
- 选择会自动保存，退出并重新打开后恢复。
- “登录时启动”读取系统的真实注册状态；如系统要求批准，点击面板里的“打开登录项设置”。
- 点击齿轮打开设置，选择菜单栏是否显示日期、是否显示秒数。秒数开关同时作用于时钟面板。
- 不显示秒数时按整分钟刷新；显示秒数时按整秒刷新。切换开关、唤醒与系统时间改变后立即刷新，定时器允许少量调度延迟以减少唤醒。
- 设置页的时区选择使用 AppKit 原生文字菜单，避免展开全部时区时创建数百个 SwiftUI 菜单视图；搜索仍覆盖系统全部时区。
- 界面支持简体中文、繁体中文和英文，语言切换立即生效；“跟随系统”使用系统首选的受支持语言，不支持的语言回退到英文。

常用城市名称随界面语言切换，其他城市使用系统时区标识中的城市名。搜索匹配当前语言显示名称、系统本地化时区名称和时区标识。可以搜索 `北京`、`Los Angeles`、`America/New_York` 等。

## 系统外观调度

设置中可以启用调度，并选择任意系统时区。默认关闭，默认计划为北京时间 07:00 切换浅色、19:00 切换深色；两个时间可修改，但不能相同。外观计划与菜单栏常驻时区独立保存。

首次启用时，macOS 会询问是否允许 TimezoneClock 控制“系统事件”。允许后，应用会出现在“系统设置 → 隐私与安全性 → 自动化”中。如果没有弹窗，点击“检查／请求授权”；如果已拒绝，点击“自动化设置”重新允许。

macOS 外观设为“自动”时，应用会暂停外观切换并提示选择“浅色”或“深色”。完成授权、选择固定外观后，工具接管后续切换。应用不直接修改系统的自动外观偏好，也不修改系统时区。

计划使用指定时区的实际时间，自动处理夏令时。夏令时跳过的时间延后到下一个有效时间，重复的时间使用第一次出现。启动、唤醒和系统时间改变后立即检查，平时每分钟检查；仅在需要时写入系统外观。手动改变外观会保留到下一次计划切换；重启应用或修改计划后重新按计划检查。关闭调度会保留当前外观。

## 构建与检查

要求 macOS 14 或更新版本，以及支持 Swift 6 的 Xcode。项目不使用第三方依赖。

```sh
./check.sh
xcodebuild -project TimezoneClock.xcodeproj -scheme TimezoneClock \
  -configuration Release -derivedDataPath /tmp/TimezoneClockBuild build
```

构建产物位于 `/tmp/TimezoneClockBuild/Build/Products/Release/TimezoneClock.app`。Xcode 工程使用本机运行签名；当前交付用于本机，不包含商店发布、公证或自动更新。

登录启动前请将应用放在稳定的位置，例如 `/Applications/TimezoneClock.app`，并从该位置启动。更新已安装的应用前先从时钟面板退出，替换后再打开。
本机临时签名随构建变化，更新后 macOS 可能要求重新授予自动化权限。

检查脚本覆盖时间换算、日期与秒数、三种语言资源、时区选择、配置恢复、跨日和冬夏令时调度及手动覆盖。它不代替系统授权、实际重新登录或休眠唤醒验证。

## 系统时区

在“系统设置 → 通用 → 日期与时间”中，保持自动设置日期与时间，关闭根据当前位置自动设置时区，选择洛杉矶。

应用独立使用每个时区的标识换算同一个当前时刻，自动处理夏令时，不更改系统时区或实际时刻。
